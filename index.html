Как опубликовать на GitHub Pages

  1. Создайте на GitHub репозиторий, например pages-practice.
  2. Загрузите в ветку main три файла: index.html, style.css, script.js.
  3. Откройте Settings → Pages и выберите Source: Deploy from a branch, ветку main, папку / (root). Нажмите Save.
  4. Подождите 1–2 минуты — сайт откроется по адресу https://ваш-логин.github.io/название-репозитория/.

Картинки, стили и скрипты подключены относительными путями (style.css, а не /style.css) — поэтому страница работает и в корне домена, и в подпапке репозитория.
